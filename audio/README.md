# Nebula 3 sound effects

The five MP3 sound effects are from Kenney's CC0 audio packs, distributed locally with the game so combat audio does not depend on a third-party server. The original OGG files were transcoded to MP3 by the [Brickstorm project](https://github.com/manuel-palacio/brickstorm/blob/main/CREDITS.md); filenames here reflect their use in Nebula 3.

| File | Original Kenney sound | Pack |
| --- | --- | --- |
| `laser.mp3` | `laserSmall_001.ogg` | [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds) |
| `impact.mp3` | `impactMining_000.ogg` | [Impact Sounds](https://kenney.nl/assets/impact-sounds) |
| `explosion.mp3` | `explosionCrunch_000.ogg` | [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds) |
| `shield.mp3` | `impactPlate_light_002.ogg` | [Impact Sounds](https://kenney.nl/assets/impact-sounds) |
| `alert.mp3` | `jingles_HIT09.ogg` | [Music Jingles](https://kenney.nl/assets/music-jingles) |
